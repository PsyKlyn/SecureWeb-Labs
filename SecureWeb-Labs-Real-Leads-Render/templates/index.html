FAQ

Questions? We've got answers.

Important information before requesting an assessment.

What types of websites can be assessed?

Websites and web applications can be assessed when the owner or authorized party has approved the testing and the scope is clearly defined.

What will I receive?

A report can document identified findings, relevant evidence, risk context, and practical remediation recommendations based on the agreed scope.

How long does an assessment take?

Timing depends on the size and complexity of the application and the agreed scope. The schedule should be confirmed before testing begins.

Will testing take my website offline?

Testing should be scoped to minimize unnecessary disruption. Production testing requires explicit authorization and appropriate safeguards.

Do you fix vulnerabilities?

The assessment can include remediation guidance. If implementation support is offered, it should be agreed separately with the client.

Do you test websites without permission?

No. Security testing should only be performed against systems for which you have explicit authorization.
